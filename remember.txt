1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
CaptionCraft (Captive.ai) ek fully offline, single-user automated Reel/Shorts 
Captioning & Kinetic Video Editor tool hai. 
Iska main goal: CapCut / Opus Clip jaisi word-by-word kinetic animated captions 
video par burn karna — 100% local machine par, bina kisi cloud upload, API key, 
login ya payment ke.

--------------------------------------------------------------------------------
2. THREE-LAYER OFFLINE ARCHITECTURE (IMPLEMENTED)
--------------------------------------------------------------------------------

[LAYER 1 — STT & Forced Alignment (Python FastAPI Backend)]
1. Audio Extractor (`backend/services/audio_extractor.py`):
   - Local FFmpeg se video se 16kHz mono 16-bit PCM WAV nikalta hai (`pcm_s16le`, `-ar 16000`, `-ac 1`).
   - Faster-whisper input ke liye optimized.

2. Forced-Alignment Engine (`backend/services/transcriber.py`):
   - `faster-whisper` (`small` model, int8 CPU quantization) with `word_timestamps=True`.
   - 500+ Creator Hinglish words dictionary (mujhko, humara, sensor, video, nahi, chalega, etc.)
   - Strict Output Schema:
     [{"word": "nahi", "start": 1.2, "end": 1.5}, {"word": "ho", "start": 1.5, "end": 1.7}]
   - Supported Modes: Only "hinglish" (Roman Hindi) & "english".

3. FastAPI Backend Server (`backend/main.py`):
   - Serving on: `http://127.0.0.1:8000`
   - Endpoints:
     * `GET /health`: Health status & output folder verify.
     * `POST /transcribe`: Accepts file upload / local video path, returns strict word JSON.
     * `POST /export`: Burns captions directly to MP4 via FFmpeg and saves to `/output`.
     * `GET /output/{filename}`: Static video downloads.

[LAYER 2 — Caption Rendering & Animation (React Frontend)]
4. 60FPS Canvas Animation Engine (`src/utils/captionAnimation.js`):
   - HTML5 Canvas API par Skia `drawGlyphs` jaisa pixel-perfect renderer:
     Custom fonts, thick stroke borders, drop-shadows, glow highlights, aur behind-text blend modes.
   - Reanimated worklets jaisi smooth kinetic pop animations (`easeOutBack` spring curves).

5. Caption Presets Config (`src/config/captionPresets.json`):
   - Hormozi Pop (Yellow/Gold bold punch, uppercase, glow)
   - Karaoke Highlight (Montserrat, green active word lighting)
   - Minimal Clean (Inter, smooth subtle bounce)
   - Behind Text Cinematic (Impact uppercase, text behind subject effect)

6. Languages Config (`src/config/captionLanguages.json`):
   - Hinglish (Roman Hindi) & English rules.

7. Caption Preview Component (`src/components/CaptionPreview.jsx`):
   - Video element ke upar synchronized 60fps HTML5 Canvas overlay.
   - `requestAnimationFrame` loop se word-level accurate kinetic highlights.

[LAYER 3 — Local Video Exporter]
8. Hardware MP4 Exporter (`backend/services/exporter.py`):
   - Advanced SubStation Alpha (`.ass`) dynamic style generator with word tags.
   - Local FFmpeg filter graph (`subtitles`) se direct hardware burn-in.
   - Final MP4 reel automatically `scratch/caption-craft/output/` folder me save hoti hai.
