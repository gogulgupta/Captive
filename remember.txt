3. FILE STRUCTURE & IMPORTANT CHANGES
--------------------------------------------------------------------------------
- server.py:
  Local backend service (Flask + faster-whisper + Hinglish transliteration engine).
  Port: http://127.0.0.1:5000. Endpoint: POST /transcribe.

- src/utils/aiTranscription.js:
  Video se WebAudio API ke through 16kHz WAV nikalta hai aur local Python server ko bhejta hai.

- src/components/CaptionTimeline.jsx:
  AI Auto-Captions button, Hinglish/English language toggle, word editing, timestamp jumping,
  emoji picker aur script paste interface.

- src/components/VideoPlayer.jsx:
  Dynamic captions rendering, Hormozi kinetic bounces, word pop animation, audio ducking,
  SFX trigger aur safe-zone guides.

- src/components/StyleCustomizer.jsx:
  Fonts, colors, text stroke, Y-position, aur words-per-frame (Auto Voice Sync, 1, 2, 3) controls.

- src/components/ExportModal.jsx:
  MP4 export dialog with 720p / 1080p / 4K and 30fps / 60fps selection + real-time canvas
  video rendering and audio merging.

- src/App.jsx:
  Main layout, state management (videoSrc, videoFile, words, style, duration), tab switching.
